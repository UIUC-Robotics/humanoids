This repo indexes the projects, repositories, and resources where humanoid work actually lives, so anyone on campus can find what exists, who owns it, and how to get access.

## Add your project

Starting humanoid work at UIUC? Get it listed:

1. Fork this repo or create a branch.
2. Add a row to the [Projects](#projects) table. Fill in every column, including the access level and today's month under **Last verified**.
3. If you're working on a robot that isn't listed yet, add it to [Platforms](#platforms).
4. Open a pull request. A maintainer will review it within a week.

**Guidelines**
- Link to repos and docs. Don't copy code into this repo.
- Never commit credentials, robot IPs, or network configs here.
- If you leave UIUC or hand off a project, update the **Contact** column.
